INLA screen: eDNA signal, distance, and time since sampling

Author

Sam Matthews

Purpose

This fast first pass asks a narrower operational question than the full SPDE benchmark: how well do eDNA percent positive, mean concentration, distance from the eDNA sampling event, and days since that event explain subsequent COTS cull counts? Spatial and temporal context enter directly through distance and lag. All models retain one response per cull dive, use a negative-binomial likelihood with effort offset, and include a reef random intercept. No calendar-year or GBR-wide latent spatial field is fitted.

Operational eDNA-event linkage

Each cull is paired with its most recent eligible prior eDNA event on the same reef and within 2,000 m and 183 days. Replicates within that event supply percent positive and mean concentration. If multiple events have the same lag, the nearest site is selected. This rule is fixed before inspecting CPUE.

All additive subsets

The four continuous predictors are transformed and standardized once, then the same complete observations are used for all 16 additive subsets (including the reef-only null model). Concentration uses log1p; distance uses log1p(distance / 200); lag uses log1p(days).

Hierarchical interaction screen

Interactions are tested only with all corresponding main effects retained. Six models add one pairwise interaction at a time; a final model includes all six pairwise interactions. Higher-order interactions are deferred because they are hard to interpret and are more likely to fit sampling idiosyncrasies.

Combined ranking and supported effects

WAIC is the primary fast ranking criterion; mean log CPO is retained as an observation-level predictive check. A later brms analysis should validate the shortlist using grouped cross-validation by reef or sampling event rather than selecting solely on in-sample information criteria.

Interpretation boundary

This screen estimates association and predictive support, not eDNA transport or causal decay. The selected eDNA event is an operational anchor, and alternative nearest-event and 365-day link rules should be sensitivity analyses. The best few formulations should next be refitted in brms with grouped out-of-sample validation and posterior predictive checks before choosing a final model.
