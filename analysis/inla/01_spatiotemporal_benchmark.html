Spatio-temporal INLA benchmark for eDNA-informed COTS CPUE

Author

Sam Matthews

Purpose

This is the first executable milestone from INLA_IMPLEMENTATION_PLAN.md. It creates audited raw eDNA/cull links, aggregates those links to one response per cull dive, fits a negative-binomial spatio-temporal INLA benchmark, and generates site-level CPUE predictions for 0, 200, 500, 1000, and 2000 m distance scenarios.

The benchmark deliberately precedes the joint raw-replicate likelihood. Raw eDNA rows are preserved in the linkage table, but the same cull count is never copied across replicate rows.

Mesh and prediction scenarios

The first benchmark uses annual AR(1) groups because the linked observations cover eight years and monthly coverage is sparse. The spatial mesh is intentionally coarser than the 200–2000 m fixed distance effect: the SPDE captures broad residual dependence, while distance is estimated directly as a covariate.

Code 
if (reuse_saved_fit) {

  mesh <- inla_benchmark$mesh
} else {

distance_summary <- site_predictions_table %>%
  group_by(distance_scenario_m) %>%
  summarise(
    median_cpue = median(cpue_mean),
    median_q10 = median(cpue_q10),
    median_q90 = median(cpue_q90),
    median_prob_gt_002 = median(prob_cpue_gt_002),
    median_prob_gt_004 = median(prob_cpue_gt_004),
    .groups = "drop"
  )

p_distance <- ggplot(distance_summary, aes(distance_scenario_m, median_cpue)) +
  geom_ribbon(aes(ymin = median_q10, ymax = median_q90), fill = "#3182bd", alpha = 0.22) +
  geom_line(color = "#08519c", linewidth = 1) +

Interpretation boundary

This benchmark is an implemented checkpoint, not the final causal or transport model. It uses event-level eDNA summaries as covariates while retaining raw replicate links for audit. The next model stage must add the planned joint Bernoulli detection and conditional concentration likelihoods sharing the latent field. Reef-level posterior aggregation must use posterior samples so spatial covariance is retained; averaging marginal credible limits is not an acceptable reef-level uncertainty calculation.
